# Grid World Movement
Started 07/09 2026 and finished 09/09 2026.
Second project I've made in C++, mainly to learn basic fundamentals without any dependencies. 
Minimal AI usage to learn, mostly used if i was stuck on a bug for 45 minutes.

It is essentially a little robot that can move around in a grid, that is defined by a config file. 
You can give it multiple move orders without leaving the grid. 

I have a much better understanding of how to structure C++ and i would definitely have made different early choices, if i were to start over. 
Should definitely have followed the DRY principle, a lot of the code is repeated and unnecessary, but very simple.
I learned how to use the multifile system in C++, practiced how to make different methods, read files, how to use matrices and C++ datatype fun.
